# OpenHC 4.4

**开源的 HiCar 车机端（Android 4.4 分支）。** 装在安卓车机上，华为手机无线投屏到车机屏幕。

[下载安装包](https://github.com/ma452191078/OpenHC-4.4/releases/latest) · [更新记录](CHANGELOG.md) · [报告问题](https://github.com/ma452191078/OpenHC-4.4/issues) · [从源码构建](#构建)

> 这是 [OpenHC](https://github.com/GGBondLab/OpenHC) 的 Android 4.4 适配分支，面向 API 19 起的老车机（如吉利 ECARX CS11 / Android 4.4.3）。
> 主线功能以无线投屏为主，有线连接默认隐藏。其他品牌车机、非纯血鸿蒙手机上的问题，作者没有设备，无法复现和修复；欢迎有能力的朋友自己调试，提交修复。

## 0.0.1

装在**车机**上，不是手机上。不需要 root、ADB、系统签名，不依赖车机自带的 HiCar，不用注册账号，不连任何服务器。
车机要允许安装 APK。

- **无线**：车机安卓 4.4 起。打开应用直接显示二维码，手机扫码连接；连成功过一次后，上车自动回连。
- **有线**：默认隐藏，可在 设置 → 连接方式 里启用；手机需关闭「USB 调试」。
- **手机**：带 HiCar 的华为或荣耀手机（作者只在纯血鸿蒙手机上测试过）。

## 功能

- 连接：所有版本打开应用即显示连接二维码；未配对时等待扫码，已配对时后台自动回连；手机端主动断开后回到二维码页，可点「开始连接」或重新扫码。
- 画面：帧率自动跟随车机屏幕刷新率；清晰度三档可选；可全屏，也可保留车机底部导航栏。
- 触摸：多指操作，地图可以双指缩放。
- 声音：音乐和导航播报分开放；可以在设置里分别指定导航声道和音乐声道（编号同 DiPlay），带试听。
- 方向盘按键：上一首、下一首、播放 / 暂停。
- 免码回连：第一次输入车机上显示的连接码，之后不用再输。
- 自动连接手机：手机蓝牙连上车机、或打开 OpenHC（含开机自动打开）时，车机主动去连用无线连成功过的手机，不用扫码；另有 8 秒轮询兜底部分不投递蓝牙广播的车机。
- 应用内更新：设置 → 更新，从本仓库的 GitHub Releases 检查新版本，下载后按发行页的 SHA256 与本应用签名校验再安装。
- 诊断：设置 → 诊断 → 导出诊断日志，出问题时导出文本文件即可，不用接 ADB。
- 仪表盘多媒体（试验）：在 ECARX 车机上把当前蓝牙音乐信息投到仪表盘；其他车机没有对应系统服务时自动跳过。

## 使用

1. 车机安装 OpenHC（[下载](https://github.com/ma452191078/OpenHC-4.4/releases/latest)）。装过自己编译的调试包的，先卸载再装，签名不同不能覆盖。
2. **无线**：打开 OpenHC，用手机相机或 HiCar 扫车机屏幕上的二维码；第一次输入车机显示的连接码。连成功过一次以后，上车手机蓝牙连上车机，OpenHC 就会自己连上手机。
3. 手机端主动断开后，车机回到二维码页；点「开始连接」让车机主动回连，或直接用手机重新扫码。

## 状态

无线投屏、自动回连与二维码主流程已在吉利 ECARX CS11（Android 4.4.3）和魅族 MX4（Android 5.1）上联调，部分场景仍需真机复测（见 [TODO](docs/TODO.md)）。

已知限制：

- 用过车机自带 HiCar 或同类应用的手机，第一次连 OpenHC 可能失败：在手机 HiCar 里删掉旧的车机记录，再扫码连接。
- 无线连接期间车机开着热点，车机自己的 WiFi 会断开；结束后安卓 10 起的车机可能要手动打开 WiFi（或打开「无线结束后恢复车机 WiFi」）。
- 车机热点在 2.4 GHz，和蓝牙在同一个频段：蓝牙正忙或手机在后台频繁定位时，画面可能比较卡；无线时声音偶尔有很短的停顿。
- 通话和车机麦克风还没有验证。
- 安卓 10 起：OpenHC 在后台时，手机蓝牙连上车机要它自己弹出来、以及开机自动打开，都要先在 设置 → 启动 里打开悬浮窗权限；自己打开 OpenHC 再连则用不着。
- 「5 GHz 直连」仅在安卓 10 起的车机上可选，低版本置灰；该模式下界面显示的热点频率仍是推测值，不影响实际连接。
- 仪表盘多媒体只对 ECARX 车机生效，且目前主要覆盖车机蓝牙 AVRCP 音源；HiCar 通道内的媒体元数据尚未实现，第三方应用能否绑定 DiServer 仍需实机确认。
- 应用内更新从 GitHub Releases 获取：发行说明里必须写 SHA256，否则不会下载安装；国内网络失败时可直接去 Releases 页手动下载。
- 只支持带 HiCar 的华为/荣耀手机（建议纯血鸿蒙）；其他品牌车机、非纯血鸿蒙手机上出现的问题，作者没有设备，多半没法修。

## 构建

需要 JDK 17 和 Android SDK 36：

```sh
./gradlew check assembleDebug
```

安装包会统一归档到 `dist/`，命名规则为 `openhc-android4.4-<版本>.apk`（debug 包带 `-debug` 后缀）。代码结构见 [架构说明](docs/ARCHITECTURE.md)。

要连得上手机，还需要一份连接参数文件 `openhc-identity.json`（不随源码发布，格式见 [示例](docs/identity.example.json)）：
把它单独放进一个目录（仓库里的 `identity/` 已被忽略），在 `local.properties` 里写 `openhc.identity.dir=<目录>`（或设环境变量 `OPENHC_IDENTITY_DIR`），构建时会打进安装包。

## 报告问题

请在 [Issues](https://github.com/ma452191078/OpenHC-4.4/issues) 里写明：车机型号和安卓版本、手机型号和系统版本、有线还是无线、操作步骤、期望和实际结果、出问题的时间，并附上诊断日志：在 OpenHC「设置 → 诊断 → 导出诊断日志」生成的文件
（安卓 10 起在「下载/OpenHC」文件夹；更早的系统在 `Android/data/io.github.gcbond.openhc/files/OpenHC`）。

安全问题和连接参数的说明见 [安全说明](SECURITY.md)。
